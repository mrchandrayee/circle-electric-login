A responsive recreation of the Circle Electric Login UI from the uploaded screen recording.

## Features
- Circular animated cyan/blue electric ring
- Dark navy login card inside the circle
- Neon glowing Login heading
- Username and Password inputs
- Blue gradient Sign In button
- Required-field validation and inline feedback
- Demo sign-in loading/success state
- HTML snippet with Copy HTML button
- Responsive layout and reduced-motion support
- No dependencies or build tools

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000.

## Project files
- `index.html` — login form, preview caption and HTML snippet
- `style.css` — circular neon ring, glow effects, form and responsive styling
- `script.js` — form validation, demo submit behavior and copy button

## Authentication note
This is a front-end visual demo. It accepts any non-empty username/password and shows a demo success state. It does not authenticate against a real account. Connect a secure backend API for production use.

## Extraction note
The video visibly shows a circular electric cyan/blue login ring, username/password fields, a blue Sign In button, the "Circle Electric Login" caption, and a visible HTML code panel. This project recreates the visible design and interaction as runnable code; source that is not legible in the recording has been reconstructed, not claimed as verbatim original code.
